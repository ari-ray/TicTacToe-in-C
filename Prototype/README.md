# Tic Tac Toe in C: PROTOTYPE

This folder contains the prototype of the TicTacToe game in C. I made this prototype right after learning the basic of C and it is solely made based on the fundamentals of C (even excluding arrays). 
Later as I progressed, I gradually got exposed to recursion and improved problem-solving techniques. Then eventually I revisited the project to practically implement the Minimax algorithm, which relies heavily on recursion.

## Features
- Console based Tic Tac Toe game
- Multiplayer mode (PvP)
- Single player mode with basic AI (random move generation)
- Fully interactive terminal interface
- Input Validation
- Win detection for rows, columns and diagonals
- Draw detection
- Option to quit mid-game
- Replay functionality without restarting
- Board visualization using a labeled grid
